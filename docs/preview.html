MysticChest v2

Мистические сундуки в стиле FunTime · Paper/Spigot 1.12.2 → 1.21.11 · один jar (Java 8 байткод, ~330 КБ) · RU / EN

1. Что добавлено в v2

Языки RU / EN

  • language: en — первая настройка в config.yml (по умолчанию EN)
  • ru, auto (язык клиента игрока), свой lang/xx.yml
  • Имена тиров на нескольких языках в tiers.yml

Конфиги с туториалами

  • ## — объяснения и рецепты, # — готовые примеры
  • Автодобавление новых разделов при обновлении, комментарии не теряются
  • Валидация: ошибка с путём ключа + откат на дефолт

4 режима выдачи

  • ROULETTE (SINGLE / SCROLL), FULL_CHEST, INSTANT, PICK
  • Глобально и на каждый тир

4 режима спавна

  • RANDOM_WORLD, NEAR_PLAYER, FIXED_POINTS, AIRDROP
  • Несколько профилей одновременно; триггеры INTERVAL / TIMES

Кулдауны и лимиты

  • Открытие, покупка, claim, спавн; scope PLAYER / PLAYER_TIER / GLOBAL
  • Лимиты в день, pity-система, права обхода

Лут из инвентаря + GUI-редактор

  • /mystic loot add забирает весь инвентарь в пулл
  • Команды-награды, вес, шансы, редактор прямо в игре

2. Файлы плагина

plugins/MysticChest/
  config.yml      глобальные настройки (язык, режимы, кулдауны, спавн, эффекты, оптимизация)
  tiers.yml       цена, имя (по языкам), open-mode, кулдауны и лимиты тира, pity
  loot/<тир>.yml  пулл наград (пишет /mystic loot и GUI-редактор)
  lang/en.yml  ru.yml
  data/players.yml   кулдауны, дневные счётчики, pity (атомарная запись)
  data/active.yml    живые сундуки (очистка после краша)
  data/points.yml    точки FIXED_POINTS

Фрагмент config.yml — так выглядят описания и туториалы:

## ═══ HOW REWARDS ARE GIVEN ════════════════════════════════════
## Default way to open a chest (every tier can override it with "open-mode"):
##   ROULETTE   - animated spin, the prize lands in the middle
##   FULL_CHEST - a chest GUI full of loot, the player takes what they want
##   INSTANT    - everything goes straight to the inventory, no GUI
##   PICK       - mystery cards: pick N face-down cards
default-open-mode: ROULETTE

## Recipe "classic FunTime":  click-air: NONE  /  click-block: PLACE
use:
  click-air: OPEN
  click-block: PLACE

## Seconds between two chest openings.  e.g. 3600 = once per hour.
cooldowns:
  scope: PLAYER_TIER
  open-seconds: 0

4. Режимы спавна

modeГде появляетсяОсобенности
RANDOM_WORLDСлучайная точка в радиусе от спавна мираграница мира, мин. дистанция, чёрный список блоков (вода, лава, листва…)
NEAR_PLAYERРядом со случайным онлайн-игроком (min..max блоков)игрок получает личное уведомление
FIXED_POINTSОдна из точек /mystic point add <имя>можно ограничить списком имён
AIRDROPПадает с неба за fall-secondsместо: RANDOM_WORLD или NEAR_PLAYER; анонс с обратным отсчётом

Триггеры: INTERVAL (каждые N минут), TIMES (["12:00","20:00"]) и ONLINE_THRESHOLD (когда онлайн ≥ N, не чаще раза в M минут). Анонс: EXACT координаты · REGION район · HINT «≈150 блоков на северо-запад» · NONE. Чанк с сундуком удерживается plugin-ticket'ом, пока сундук жив.

6. Пулл наград: команды и GUI-редактор

Команды mysticchest.admin.loot

  • /mystic loot add <тир> [вес] [--keep] [--hand] — весь инвентарь → в пулл, предметы забираются
  • loot addcmd <тир> <вес> <команда> — награда-команда, иконка = предмет в руке
  • loot cmd <тир> <#> add [p:] [50%] <команда> / remove n / list / clear
  • loot weight|remove|list|edit|clear, /mystic preview <тир>

Запись в loot/<тир>.yml

- id: a1b2c3
  material: NETHER_STAR   # или item: (полный NBT)
  amount: 1
  weight: 2
  broadcast: true
  commands:
    - run: CONSOLE
      command: kit crusher {player}
      chance: 100

Управление записью

  • ЛКМ / ПКМ — вес +1 / −1, Shift — ±10
  • F — ввод команд в чат (p: от игрока, 50% шанс, -2 удалить, clear)
  • Клавиша 1 — объявлять всем · клавиша 2 — выдавать предмет вкл/выкл
  • Q дважды — удалить
  • Предмет курсором на окно или Shift-клик по инвентарю — добавить в пулл
  • В lore каждой записи: шанс %, вес, количество, команды, редкость

7. Оптимизация — измеренные цифры

0
задач Bukkit в простое (/mystic perf: «Bukkit tasks owned: 0», очередь таймера 0)
~30 µs
бросок лута (бинарный поиск по кумулятивным весам, O(log n))
2–4 мс
открытие рулетки в установившемся режиме (создание GUI и отправка пакетов — работа сервера); первое открытие после старта ≈ 30 мс из-за JIT
0 утечек
после 150 циклов GUI + 60 открытий и GC число объектов плагина в куче совпало с исходным (jcmd GC.class_histogram)
331 КБ
jar (с XSeries, minimize()), было 597 КБ
atomic
запись файлов: tmp + rename, в фоне, debounce 5 с; после kill -9 кулдауны сохранились, сундуки и голограммы очищены
  • Один общий планировщик дедлайнов (TTL, спавн-профили, отложенные сохранения) — ни одной задачи «на сундук» или «на игрока».
  • Один общий тикер анимаций: живёт только пока кто-то крутит рулетку.
  • Кеш GUI магазина и превью по языку; сбрасывается при reload и изменении лута.
  • Поиск места для спавна: ограниченное число попыток, асинхронная загрузка чанков на Paper 1.13+.
